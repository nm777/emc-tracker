# AGENTS.md

## Versioning and Changelog

When making changes that affect the user-facing app (features, bug fixes, UI changes), **always**:

1. **Increment the version** in `package.json`:
   - **Patch** (`1.1.1` → `1.1.2`): bug fixes, small tweaks
   - **Minor** (`1.1.1` → `1.2.0`): new features
   - **Major** (`1.1.1` → `2.0.0`): breaking changes requiring data migration

2. **Add an entry to `CHANGELOG.md`** under a new version heading at the top (below the semantic versioning explanation). Use `### Added`, `### Changed`, or `### Fixed` sections. Include today's date in `YYYY-MM-DD` format.

3. Documentation-only changes (README, comments) do not require a version bump.

## Running the App

```bash
node server.js          # start the web server (http://localhost:3000)
node index.js           # standalone data collection (no server)
node validate.js        # validate EMC formula against USDA reference table
```

## Architecture

- `server.js` — web server, API endpoints, and data collection
- `index.js` — standalone data collection script (shares EMC logic)
- `index.html` — dashboard UI (charts, config panel, print layout)
- `cities.json` — project configuration (generated by the UI)
- `emc_log.csv` — daily EMC summaries (append-only)
- `data.js` — generated chart data loaded by the browser
